# Играбельный участок «Галерея Г-4»

Исходная точка — проект v0.1. Теперь в основной сцене есть открытый вход на восточной окраине (24, 0, −20). За ним пять стыкуемых секций спуска, внизу — аптечка. Предмет и положение игрока сохраняются штатной системой v1. Посёлок, склад и лес пока в блокинге.

| Параметр | Галерея Г-4 |
|---|---|
| Asset ID | RZ_ZONA_ENV_GALLERY_G4_001 |
| Исходник | tools/build_gallery.py, Python 3 + Pillow |
| Экспорт | assets/bunker/gallery.gltf, Y-up, метры |
| Геометрия секции | 494 треугольника, один меш, одна поверхность |
| Пиксельный атлас | gallery_atlas.png, 128 × 64, один материал |
| Габариты | 4,08 × 4,28 × 4 м с учётом уклона |
| Точки стыковки | Вход (0,0,0), выход (0,−1,−4) |
| Коллизии | Неподвижная треугольная сетка каждой секции |
| LOD | Включена генерация при импорте. Ручной LOD отсутствует |
| Приёмка | Импорт и проход штатной капсулой игрока в Godot 4.7.2, Linux headless |
| Два ракурса | docs/gallery/threshold.jpg, docs/gallery/return.jpg — Blender Cycles из экспортированной геометрии |
| Связанные задачи | #128, #132 |

В корневом каталоге проекта последовательно выполнить:

```sh
python3 tools/build_gallery.py
godot --headless --import
python3 tests/test_project.py
XDG_DATA_HOME="$(mktemp -d)" godot --headless --fixed-fps 60 -s tests/bunker_walk.gd
```

Последняя проверка ведёт игрока от подхода до аптечки, подбирает её, сохраняет игру, пересоздаёт сцену и возвращает игрока на поверхность. Для повторения иллюстраций используется Blender в фоновом режиме с tools/render_gallery.py. Коллизии мелких деталей можно упростить после профилирования. Приёмка на телефоне и игровой захват в Android ещё предстоят.
