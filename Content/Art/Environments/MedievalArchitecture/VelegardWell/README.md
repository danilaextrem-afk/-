# Велеград · авторский каменный колодец 1348

3D-меш окружения: раздельные каменные кладочные сегменты, деревянные стойки, многочисленные объёмные кровельные доски, старый деревянный ворот с ручкой и намотанной верёвкой, пустотелое бочкообразное ведро, металлические обручи, декоративные семь колоколов. Полностью оригинальная процедурная геометрия, без сторонних моделей.

**Реальный результат:** OBJ LOD0 (11102 треугольников) и LOD1 (4678 треугольников), назначенные материалы MTL, UV и нормали; генератор исходников в `Tools/Art/generate_velegard_well.mjs`.

**Сборка:** `node Tools/Art/generate_velegard_well.mjs` из корня репозитория. 1 единица = 1 метр, Z вверх. В модели несколько групп материалов. Объект статический: анимация вращения ворота пока не подключена, для этого потребуется разнести подвижные части на самостоятельные игровые компоненты. Назначение: селение возле Велеграда, береговые/кузнечные районы 1348.

**Не готово к AAA/релизу:** финальный PBR (пока только scalar roughness/metalness, без texture maps), авторская скульптура/износ, собственные коллизии, UE5-импорт, освещение, контроль UV-пересечений и Nanite/LOD в движке, замер FPS. Не выдавать структурную проверку за UE5-художественный QA.
