# Velegard Gatehouse 1348 — original procedural 3D

LOD0: 4662 vertices, 1554 triangles; LOD1: 1278 vertices, 426 triangles. UV on all polygon corners. Timber-framed raised gatehouse, stone footings, pitched roof, iron straps and carved beams. Geometry in centimeters, +Z up. All OBJ faces are triangles.

Run `node generate_gatehouse.js` to regenerate OBJ. Textures are authored PPM draft maps, not final baked PBR and not UE5-native. No verified engine import, collision, Nanite, screenshots, 4K or FPS. Owner-approved Black Bell v3 is a visual quality floor; this WIP has not passed it.
