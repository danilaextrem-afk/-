# Veil Order Ritual Blade v0.1

Original procedural ceremonial blade for Razlom, 1348. Geometry is real OBJ mesh generated by `node generate.mjs`, with UV per vertex, four material slots, and draft P3 PPM PBR maps (BaseColor, Roughness, Metallic, Normal). Maps are **generic drafts**, not texture bakes; convert PPM to PNG/TGA before UE5 import. No LOD/collision, no in-engine acceptance. Blade axis +Y, units cm, up +Z. This file is source of truth for reproducibility.

Status: **materials_wip**. No UE5/AAA claim. Model does not yet meet accepted Black Bell v3 quality floor.
