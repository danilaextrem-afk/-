# Mira Veil Clasp v0.1 QA

Generated two actual OBJ meshes with v/vt/f and named material groups; LOD0 3811 vertices, 6156 triangles; LOD1 1276 vertices, 1868 triangles. Indexed face bounds checked in generation: 0 and 0 invalid faces. Geometry is parametric ring, concentric engraved rays, oxidized beads, rear pin. Units metres; 0.10 m width. No external asset pack.

**Not tested:** independent manifold/winding test, Blender render, true texture PBR maps, normal/AO bake, UV overlaps, UE5 import, rig/attachment, performance. PBR numeric values are provisional and not a completed material pipeline. This is geometry WIP, not art accepted.
