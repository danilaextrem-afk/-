# Ratibor forearm bracer v0.1

Original asymmetrical open leather cuff with three iron bands, bronze rivets, crossed leather laces and central fasteners. Mesh is a geometric WIP, not a production character asset. Run `node generate.js` in this directory to regenerate OBJ. Y axis follows forearm, 0.78 m length (placeholder dimensions to be fitted to Ratibor body). Open cuff boundaries are intentional. UVs are basic procedural coordinates, not packed UV islands. PBR texture bake, rig skin weights, LOD and UE5 import remain blocked pending appropriate tools. No render was produced.
