# Подъезд №9 · почтовые ящики 2026

Авторская 3D-геометрия настенной системы из 12 металлических ящиков для сцены расследования в подъезде. У каждого собственная дверца, слот письма, цилиндр замка, крепления, углубление для карточки жильца и объёмная рамка; на LOD0 проработаны цифры и признаки износа. Добавлена рамка объявления. Исходник на Node.js без внешних ассет-паков.

- LOD0: 6292 треугольников; LOD1: 4008.
- Формат OBJ/MTL, нормали, базовые UV; единицы метры, Z вверх.
- Генерация: `node Tools/Art/generate_moscow_mailboxes.mjs`.
- Материалы пока **черновые scalar PBR**, текстурные карты, коллизии, открывание дверей, отдельные подвижные mesh components, UV-бейкинг и проверка в UE5 отсутствуют. Не называть финальным AAA-ассетом.
