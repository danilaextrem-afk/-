# Предметы пролога · Россия, 2026

| Файл | Сюжетное назначение | Устройство |
| --- | --- | --- |
| Gauge/Gauge.glb | Манометр со стола мастерской Ильи, миссия 1 | Завальцованный корпус, латунный штуцер с винтовой резьбой, линза, шкала на 8 бар и стрелка на кости Spindle. Кадры 1, 21 и 41 соответствуют 0, 4 и 8 бар. |
| Entrance/Entrance.glb | Обозначение девятого подъезда, миссия 5 | Штампованная эмалированная панель с отбортовкой, следами износа и четырьмя винтами с прорезью. |

GLB содержит текстуры. Папки Maps также дают самостоятельные PNG. Color использует sRGB, Normal использует tangent space glTF (+Y), MetalRough хранит roughness в G и metallic в B. Корпус прибора и крепёж используют постоянные параметры материала. Карты манометра имеют размер 1024×1024, таблички — 2048×1024. Для автономной проверки каждого ассета рядом лежат размеры в сантиметрах, число треугольников, выпуклая коллизия в отдельном OBJ (сантиметры, Z вверх) и два снимка повторно импортированной геометрии.

Воспроизведение из этой директории (Blender 4.3.2, системный Python с NumPy, SciPy, Pillow и шрифтами DejaVu):

```sh
python textures.py
blender -b --python-exit-code 1 -P build.py
blender -b --python-exit-code 1 -P review.py
```

**Передача в UE5.** Переносить GLB через импорт сцены с сохранением иерархии и материалов. Для манометра сохранить skin и клип стрелки. Визуальный меш и отдельный OBJ коллизии имеют разные соглашения о единицах: сверить размер по review.json. Малый настольный манометр может использовать только query collision. Применение hull, проверка прозрачности линзы, дистанции читаемости шкалы, LOD и замер стоимости ждут Windows UE5. Масштаб и плоскость крепления таблички можно проверить по габариту 40×20 см.
