# Общая база Realtor AI

Один экземпляр обслуживает один офис. Сервис использует Python 3.11+ и SQLite, без дополнительных пакетов. Android-клиент открывается в «Профиль → Общая база офиса». Локальная CRM продолжает работать без сервера.

## Запуск

На сервере с закрытым доступом к файлам базы выпустите учётные записи через CLI. Выдавайте токены сотрудникам через защищённый канал.

```bash
cd realtor/office
python3 office.py --db /var/lib/realtor/office.sqlite3 issue broker1 'Риелтор' agent
python3 office.py --db /var/lib/realtor/office.sqlite3 issue lead1 'Руководитель' manager
python3 office.py --db /var/lib/realtor/office.sqlite3 serve --host 127.0.0.1 --port 8443
```

Для доступа со смартфона поставьте перед loopback-сервисом HTTPS-прокси с доверенным сертификатом, ограничением соединений и таймаутами. Прямой запуск с TLS принимает `--cert` и `--key`; клиент проверяет сертификат и отказывается отправлять токен через HTTP или перенаправления. Храните SQLite на зашифрованном томе и проверяйте резервную копию через SQLite Backup API. Файл базы, ключи сертификата и токены относятся к данным офиса.

Повторный `issue` меняет токен сотрудника и сохраняет его назначения. `revoke <id>` немедленно закрывает доступ. Администрирование учётных записей выполняется локально на сервере. Публичной регистрации нет.

## Возможности

- Сотрудники офиса читают общие карточки недвижимости.
- Риелтор видит только назначенные ему заявки покупателей. Руководитель и администратор видят все заявки и назначают ответственного.
- Пользователь выбирает запись и явно подтверждает передачу. Телефоны, переписка, личные заметки и токены платформ не входят в схему обмена.
- Обновления проверяют ревизию. При конфликте Android просит обновить список. Локальная запись сохраняется отдельно.
- Сервер фиксирует создание, редактирование, перераспределение, удаление и операции с доступом.

Интеграция распространяется на объекты и заявки. Обмен данными сделок, финансовый кабинет и автоматическое рекламное финансирование требуют отдельной реализации.

```bash
python3 -m unittest -v
```
