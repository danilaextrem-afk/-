# ZONA bunker entrance module

Original 4m-scale modular entrance facade, 1.4m x 2.25m door clearance. Procedural source is `generate.mjs`; run `node generate.mjs > bunker_entrance.gltf` to obtain embedded-buffer glTF 2.0. Face UVs, four flat PBR factors, no external packs. Current stage: geometry WIP. No Godot or Android validation.
