# РАЗЛОМ · Крепостная дорога

Первый технический прототип. Распакуйте проект, откройте project.godot в Godot 4.7.2 и нажмите F6 в сцене Content/Road.tscn или F5 для запуска проекта. Держите ↑ или «Ехать», поворачивайте стрелками. Через 20 метров средневековая дорога на четыре секунды сменится современной улицей. Кнопка «Заново» возвращает к началу.

## Проверка

Из корня проекта запустите `godot --headless --script Tests/road_test.gd` и `godot --headless --quit-after 3`. Проверено на Linux. Для проверки интерфейса в окне 4K на подходящем ПК: `godot --resolution 3840x2160`. Базовый размер интерфейса 1920×1080 с адаптацией пропорций. Экспорт и производительность Windows и Android предстоит проверить.
