# РАЗЛОМ: ЧЁРНЫЙ ЗВОН

Текущая сборка исходников открывает акт I «Ночная дорога». Откройте project.godot в Godot 4.7.2 и нажмите F5. У автосервиса сядьте за руль клавишей E. Стрелки управляют движением, ↓ тормозит, M переключает вид назад. Действия также доступны экранными кнопками. В конце поездки откройте сообщение Ильи. В журнале остаётся исход встречи на обочине до перезапуска.

Отдельная средневековая поездка запускается из Content/Road.tscn. Для проверки всех трёх исходов пролога запустите `godot --headless --script Tests/prologue_test.gd`.

## Проверка

Из корня проекта запустите `godot --headless --script Tests/road_test.gd` и `godot --headless --quit-after 3`. Проверено на Linux. Для проверки интерфейса в окне 4K на подходящем ПК: `godot --resolution 3840x2160`. Базовый размер интерфейса 1920×1080 с адаптацией пропорций. Экспорт и производительность Windows и Android предстоит проверить.

## Материалы

В корне лежат три оригинальных вложения. В Docs — рабочие документы и журнал. GameData/road_glimpse.json описывает тестовое событие. Source содержит логику сцены. Все модели в прототипе построены из примитивов.

## Расследование «Немой колокол»

После проблеска доезжайте до левой башни и осмотрите камень. Подъедьте к стражнику у правой башни, поговорите и проедьте между башнями. Кнопка действия появляется вблизи цели. На клавиатуре ей соответствует E. «Журнал» показывает улики текущей поездки, «Заново» сбрасывает задание. Сквозной тест: `godot --headless --script Tests/gate_test.gd`.
